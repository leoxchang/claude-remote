# 手机云端模式使用说明

App（Flutter）除了扫码直连 Mac 之外，还支持经云端 Relay 控制电脑：手机与电脑不需要同一网络，只要求都能访问云端地址。接口依据见 `protocol/v1/relay-contract.md`；电脑侧接入见 `docs/relay-agent-usage.md`。

一次只激活一种模式（直连或云端）。两种模式的本地数据互不覆盖。

## 前置条件

1. 云端 Relay 已部署并可通过 App 访问（生产必须 TLS）。
2. 该电脑已登录云端：`claude-agent relay login`，且 Agent 正在运行（`relay status` 显示已连接）。
3. 管理员已为该账号创建凭据（Relay 主机上执行）：

   ```bash
   RELAY_DATA_DIR=<数据目录> node apps/relay/bin/claude-remote-relay.js \
     admin create-user <用户名> --password '<初始口令>'
   ```

## App 侧步骤

1. 打开 App。未配对时在配对页底部点「使用云端账号登录」。
2. 填写云端地址（例如 `relay.example.com` 或 `https://relay.example.com`）、用户名、口令。
   - 地址可省略协议，默认按 `https://` 连接；开发环境可填 `http://127.0.0.1:8788`。
   - 地址不允许带路径、查询参数或账号信息。
3. 登录成功后进入「电脑」列表页：显示账号名下各电脑的名称、平台、在线状态与当前选择。
4. 选择一台电脑进入项目列表；之后的使用与直连模式一致（会话、流式事件、审批、附件、语音）。
5. 切换控制电脑：在项目列表页右上角点「电脑」图标，回到列表页重新选择；
   切换会以新 `desktopId` 重建连接，各电脑的会话缓存、草稿与本地提问按电脑隔离。
6. 退出云端账号：在电脑列表页点「退出账号」。确认后会吊销本机在云端的设备记录、清除 Keychain
   与当前电脑的本地缓存，并回到配对页（可重新扫码直连或再次登录云端）。

> 电脑上正在执行的 run 不会因手机退出或切换而被中断；事件事实源始终在该电脑上。

## 错误对照

| App 提示 | 含义与处理 |
| --- | --- |
| 账号或口令不正确 | 口令错误或账号不存在（两者不区分）；重新输入或联系管理员重置 |
| 账号已被禁用，请联系管理员 | 管理员禁用了该账号；联系管理员启用 |
| 账号下设备数量已达上限，请先吊销旧设备 | 账号未吊销设备达 20 台；在管理端或旧手机上退出账号 |
| 尝试过于频繁，请稍后再试 | 登录限流（每分钟 10 次）；稍后重试 |
| 无法连接云端，请检查地址与网络 | 网络不通或地址错误；确认地址与网络 |
| 云端地址无效，请输入如 https://relay.example.com | 地址格式不合法（带路径/参数/账号信息等） |
| 云端版本与 App 不兼容 | 契约主版本不匹配；升级 App 或云端 |
| 登录已失效，请重新登录 | 令牌被吊销（4004）或升级被拒（401）；重新登录 |
| 加载电脑列表失败，请重试 | 其他请求失败；下拉刷新页可重试 |

电脑显示离线（灰点）时仍可选择，但连接会持续「重连中」直到该电脑上线。

## 隐私与安全

- 设备令牌只存 Keychain；云端只保存其哈希，第一次登录响应外不再出现。
- 云端在 TLS 保护下可见明文转发内容，但**不持久化**任何帧或应答体；账号之间完全隔离。
- 模型密钥与 ASR 密钥只存在于电脑端；手机与云端均不接触。
